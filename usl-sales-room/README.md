# U.S. Lawns MEG Sales Room

24 self-contained pages for the U.S. Lawns Mutual Evaluation Guide, built on
the same pipeline as the 1-Tom-Plumber, Kitchen Guard and The Seals rooms.

## Layout

```
spec/page-template.html   the brand's design - supplied as the styled Stage 1
                          Welcome page. Replace it and rebuild; it is a drop-in.
spec/structure.json       the 24-page map, gates, milestones (shared MEG shape)
content/pages/*.md        the copy, generated by build/adapt_copy.py from the
                          1-Tom source, split by "## PAGE: <path>" headers
build/                    the generator
dist/                     the 24 built pages + INDEX.md (gitignored)
usl-meg-pages.zip         the packaged pages
preview.html              single-file preview of all 24 pages
copy-sheet.html           per-section copy for CMS paste
```

## Rebuild

```bash
python3 usl-sales-room/build/adapt_copy.py     # regenerate copy from the 1-Tom source
python3 usl-sales-room/build/build.py          # build 24 pages + INDEX.md, run checks
python3 usl-sales-room/build/subset_fonts.py   # re-subset fonts after copy changes
python3 usl-sales-room/build/viewer.py         # preview.html
python3 usl-sales-room/build/copysheet.py      # copy-sheet.html
```

## Brand notes

- **Copy baseline** is the 1-Tom source as reconciled to the live CMS export on
  2026-08-19: B-Verify financial and background verification (link unwired for
  this brand), no sub-step lists or closing cards on index pages, pointer as
  prose in the body copy.
- **Palette and journey art** come from the supplied template, which documents
  the U.S. Lawns Brand Guidelines v1.1 (June 2025) swatches. The journey is a
  lawn per stage: mown behind you, the mower on the current stage, tall ahead.
- **Type**: Antonio (display), Inter (UI), PT Serif (body), embedded as
  subset data URIs so no outbound font request is made. The supplied template
  links Google Fonts instead; the build replaces that with the embedded set.
- **No U.S. Lawns source copy was supplied** for territory design, premises,
  the address requirement, values, founder, leadership or training. All of it
  is flagged in-page rather than written, following The Seals precedent. The
  address-requirement gate must not go live until confirmed for this brand.
- **The welcome and brand-overview videos are pending** ("awaiting final cut"
  slots, as the supplied template shows). The EverSmith process videos carry
  across brands and are embedded.
