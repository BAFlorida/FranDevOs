# The Seals MEG sales room

Third brand on the same build. `spec/page-template.html` is the supplied draft;
copy is adapted from the 1-Tom MEG language by `build/adapt_copy.py`.

No brand book has been provided for The Seals, so unlike Kitchen Guard these
values could not be checked against Pantone or RGB specifications. They are
used exactly as the draft authored them.

## Type

Audiowide for the logo wordmark, Montserrat 600/700/800 standing in for Gotham,
Inter 400-700 standing in for Universal Next / Univers. All three are embedded
as subset woff2, so the pages make no outbound font request.

## What is confirmed and what is not

Confirmed by the draft: palette, type, logo, and the window journey icon whose
states run from fogged to clear.

Not confirmed, and therefore flagged rather than filled:

- **Territory design.** The variable territories are drawn around, and the unit
  they are counted in. Sister brands differ sharply here, so nothing transfers.
- **Premises.** Whether a physical location is required and of what type.
- **The address requirement and its gate.** The gate is carried over from the
  shared MEG language and must not go live until the requirement is confirmed
  to apply to this brand.
- **Brand-specific resources.** Values, founder, leadership, training program.
- **Technology.** The page still names ServiceTitan and CareerPlug, carried over
  because technology was confirmed shared for Kitchen Guard. Confirm the same
  holds for The Seals.
